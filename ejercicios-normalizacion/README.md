## Ejercicio 1. Archivo Regional · control de solicitudes

### A1. Atributos que violan la 1FN

- **telefono1, telefono2, telefono3** (SOLICITANTE): grupo repetitivo, el teléfono se repite en tres columnas. Solución: tabla **TELEFONO_SOLICITANTE**(dni, telefono), máximo 3 por solicitante.
- **direccion** (SOLICITANTE): no atómico, guarda calle, distrito, provincia y departamento en un solo texto. Solución: separar en **calle, distrito, provincia, departamento**.

### A2. Dependencias funcionales y dependencias parciales (2FN)

- **SOLICITANTE** (PK: dni)
  - dni → nombres, apellidos, telefono1, telefono2, telefono3, direccion
- **SOLICITUD** (PK: nro_solicitud)
  - nro_solicitud → dni_solicitante, fecha_solicitud, estado, cod_funcionario
  - cod_funcionario → nombre_funcionario, cargo_funcionario (transitiva)
- **DOCUMENTO** (PK: cod_documento)
  - cod_documento → tipo_documento, cod_fondo, anio_documento
  - cod_fondo → nombre_fondo (transitiva)
- **DETALLE_SOLICITUD** (PK: nro_solicitud, cod_documento)
  - (nro_solicitud, cod_documento) → nro_copias, fecha_entrega
  - cod_documento → descripcion_documento, ubicacion_fisica **(parcial)**

**Parcial:** en DETALLE_SOLICITUD, descripcion_documento y ubicacion_fisica dependen solo de cod_documento, así que pasan a DOCUMENTO. Las otras tablas tienen PK simple.

### A3. Dependencias transitivas (3FN) y atributos derivados

- **SOLICITUD:** nro_solicitud → cod_funcionario → nombre_funcionario, cargo_funcionario → nueva tabla **FUNCIONARIO(cod_funcionario, nombre_funcionario, cargo_funcionario)**
- **DOCUMENTO:** cod_documento → cod_fondo → nombre_fondo → nueva tabla **FONDO_DOCUMENTAL(cod_fondo, nombre_fondo)**
- **Derivados:** no hay.

### A4. Dependencias funcionales del modelo corregido

- **SOLICITANTE:** dni → nombres, apellidos, calle, distrito, provincia, departamento
- **TELEFONO_SOLICITANTE:** (dni, telefono) → solo clave
- **FUNCIONARIO:** cod_funcionario → nombre_funcionario, cargo_funcionario
- **SOLICITUD:** nro_solicitud → dni_solicitante, cod_funcionario, fecha_solicitud, estado
- **FONDO_DOCUMENTAL:** cod_fondo → nombre_fondo
- **DOCUMENTO:** cod_documento → cod_fondo, tipo_documento, descripcion_documento, ubicacion_fisica, anio_documento
- **DETALLE_SOLICITUD:** (nro_solicitud, cod_documento) → nro_copias, fecha_entrega

### A5. Modelo normalizado (PK en negrita, FK marcadas)

- **SOLICITANTE**(**dni**, nombres, apellidos, calle, distrito, provincia, departamento)
- **TELEFONO_SOLICITANTE**(**dni** (FK), **telefono**)
- **FUNCIONARIO**(**cod_funcionario**, nombre_funcionario, cargo_funcionario)
- **SOLICITUD**(**nro_solicitud**, dni_solicitante (FK), cod_funcionario (FK), fecha_solicitud, estado)
- **FONDO_DOCUMENTAL**(**cod_fondo**, nombre_fondo)
- **DOCUMENTO**(**cod_documento**, cod_fondo (FK), tipo_documento, descripcion_documento, ubicacion_fisica, anio_documento)
- **DETALLE_SOLICITUD**(**nro_solicitud** (FK), **cod_documento** (FK), nro_copias, fecha_entrega)

## Ejercicio 2. Sistema de reclamos

### A1. Atributos que violan la 1FN

- **nombre_completo** (CLIENTE): no atómico, nombres y apellidos juntos ("Ana Quispe Rojas"). Solución: separar en **nombres** y **apellidos**.
- **archivos_adjuntos** (RECLAMO): multivaluado, varios archivos separados por ; ("foto1.jpg;boleta.pdf"). Solución: tabla **ARCHIVO_ADJUNTO**(nro_reclamo, nombre_archivo).

### A2. Dependencias funcionales y dependencias parciales (2FN)

- **CLIENTE** (PK: cod_cliente)
  - cod_cliente → nombre_completo, dni, correo, telefono
- **RECLAMO** (PK: nro_reclamo)
  - nro_reclamo → cod_cliente, fecha_registro, cod_categoria, archivos_adjuntos, estado
  - cod_cliente → nombre_cliente (transitiva)
  - cod_categoria → nombre_categoria, area_responsable (transitiva)
- **AGENTE** (PK: cod_agente)
  - cod_agente → nombre, area
  - area → jefe_area (transitiva)
  - jefe_area → telefono_jefe (transitiva)
- **SEGUIMIENTO** (PK: nro_reclamo, nro_paso)
  - (nro_reclamo, nro_paso) → cod_agente, fecha_paso, accion_realizada
  - nro_reclamo → fecha_registro_reclamo **(parcial)**
  - cod_agente → nombre_agente (transitiva)

**Parcial:** en SEGUIMIENTO, fecha_registro_reclamo depende solo de nro_reclamo y ya está en RECLAMO (fecha_registro), así que se quita. Las otras tablas tienen PK simple.

### A3. Dependencias transitivas (3FN) y atributos derivados

- **RECLAMO:** nro_reclamo → cod_cliente → nombre_cliente → se quita nombre_cliente (ya está en CLIENTE)
- **RECLAMO:** nro_reclamo → cod_categoria → nombre_categoria, area_responsable → nueva tabla **CATEGORIA(cod_categoria, nombre_categoria, area_responsable)**
- **AGENTE:** cod_agente → area → jefe_area → telefono_jefe → nueva tabla **AREA(area, jefe_area) y JEFE_AREA(jefe_area, telefono_jefe)**
- **SEGUIMIENTO:** (nro_reclamo, nro_paso) → cod_agente → nombre_agente → se quita nombre_agente (ya está en AGENTE)
- **Derivados:** no hay.

### A4. Dependencias funcionales del modelo corregido

- **CLIENTE:** cod_cliente → nombres, apellidos, dni, correo, telefono
- **CATEGORIA:** cod_categoria → nombre_categoria, area_responsable
- **AREA:** area → jefe_area
- **JEFE_AREA:** jefe_area → telefono_jefe
- **AGENTE:** cod_agente → nombre, area
- **RECLAMO:** nro_reclamo → cod_cliente, cod_categoria, fecha_registro, estado
- **ARCHIVO_ADJUNTO:** (nro_reclamo, nombre_archivo) → solo clave
- **SEGUIMIENTO:** (nro_reclamo, nro_paso) → cod_agente, fecha_paso, accion_realizada

### A5. Modelo normalizado (PK en negrita, FK marcadas)

- **CLIENTE**(**cod_cliente**, nombres, apellidos, dni, correo, telefono)
- **CATEGORIA**(**cod_categoria**, nombre_categoria, area_responsable (FK))
- **AREA**(**area**, jefe_area (FK))
- **JEFE_AREA**(**jefe_area**, telefono_jefe)
- **AGENTE**(**cod_agente**, nombre, area (FK))
- **RECLAMO**(**nro_reclamo**, cod_cliente (FK), cod_categoria (FK), fecha_registro, estado)
- **ARCHIVO_ADJUNTO**(**nro_reclamo** (FK), **nombre_archivo**)
- **SEGUIMIENTO**(**nro_reclamo** (FK), **nro_paso**, cod_agente (FK), fecha_paso, accion_realizada)

## Ejercicio 3. Veterinaria Huellitas

### A1. Atributos que violan la 1FN

- **telefonos** (DUENO): multivaluado, varios números separados por coma ("976543210, 044365412"). Solución: tabla **TELEFONO_DUENO**(dni_dueno, telefono).
- **nombres_apellidos** (DUENO): no atómico, nombres y apellidos en un solo texto. Solución: separar en **nombres** y **apellidos**.

### A2. Dependencias funcionales y dependencias parciales (2FN)

- **DUENO** (PK: dni_dueno)
  - dni_dueno → nombres_apellidos, telefonos, direccion, correo
- **MASCOTA** (PK: cod_mascota)
  - cod_mascota → dni_dueno, nombre, raza, fecha_nacimiento
  - dni_dueno → nombre_dueno (transitiva)
  - raza → especie, peso_promedio_raza (transitiva)
  - fecha_nacimiento → edad (derivado)
- **ATENCION** (PK: cod_atencion)
  - cod_atencion → cod_mascota, fecha_atencion, cod_veterinario, motivo
  - cod_veterinario → nombre_veterinario, especialidad (transitiva)
  - suma de subtotales → total_atencion (derivado)
- **DETALLE_ATENCION** (PK: cod_atencion, cod_servicio)
  - (cod_atencion, cod_servicio) → cantidad
  - cod_servicio → nombre_servicio, precio_servicio **(parcial)**
  - precio_servicio × cantidad → subtotal (derivado)

**Parcial:** en DETALLE_ATENCION, nombre_servicio y precio_servicio dependen solo de cod_servicio, así que se crea la tabla SERVICIO. Las otras tablas tienen PK simple.

### A3. Dependencias transitivas (3FN) y atributos derivados

- **MASCOTA:** cod_mascota → dni_dueno → nombre_dueno → se quita nombre_dueno (ya está en DUENO)
- **MASCOTA:** cod_mascota → raza → especie, peso_promedio_raza → nueva tabla **RAZA(raza, especie, peso_promedio_raza)**
- **ATENCION:** cod_atencion → cod_veterinario → nombre_veterinario, especialidad → nueva tabla **VETERINARIO(cod_veterinario, nombre_veterinario, especialidad)**
- **Derivados** (no se guardan, se calculan): edad: se calcula con fecha_nacimiento; subtotal = precio_servicio × cantidad; total_atencion = suma de los subtotales

### A4. Dependencias funcionales del modelo corregido

- **DUENO:** dni_dueno → nombres, apellidos, direccion, correo
- **TELEFONO_DUENO:** (dni_dueno, telefono) → solo clave
- **RAZA:** raza → especie, peso_promedio_raza
- **MASCOTA:** cod_mascota → dni_dueno, raza, nombre, fecha_nacimiento
- **VETERINARIO:** cod_veterinario → nombre_veterinario, especialidad
- **ATENCION:** cod_atencion → cod_mascota, cod_veterinario, fecha_atencion, motivo
- **SERVICIO:** cod_servicio → nombre_servicio, precio_servicio
- **DETALLE_ATENCION:** (cod_atencion, cod_servicio) → cantidad

### A5. Modelo normalizado (PK en negrita, FK marcadas)

- **DUENO**(**dni_dueno**, nombres, apellidos, direccion, correo)
- **TELEFONO_DUENO**(**dni_dueno** (FK), **telefono**)
- **RAZA**(**raza**, especie, peso_promedio_raza)
- **MASCOTA**(**cod_mascota**, dni_dueno (FK), raza (FK), nombre, fecha_nacimiento)
- **VETERINARIO**(**cod_veterinario**, nombre_veterinario, especialidad)
- **ATENCION**(**cod_atencion**, cod_mascota (FK), cod_veterinario (FK), fecha_atencion, motivo)
- **SERVICIO**(**cod_servicio**, nombre_servicio, precio_servicio)
- **DETALLE_ATENCION**(**cod_atencion** (FK), **cod_servicio** (FK), cantidad)

## Ejercicio 4. Control de asistencia del personal

### A1. Atributos que violan la 1FN

- **dias_laborables** (HORARIO): multivaluado, varios días en un solo texto ("Lun,Mar,Mie,Jue,Vie"). Solución: tabla **HORARIO_DIA**(cod_horario, dia_laborable).

### A2. Dependencias funcionales y dependencias parciales (2FN)

- **EMPLEADO** (PK: cod_empleado)
  - cod_empleado → nombres, apellidos, cod_area, cod_cargo
  - cod_area → nombre_area (transitiva)
  - cod_cargo → nombre_cargo, sueldo_base (transitiva)
- **ASISTENCIA** (PK: cod_empleado, fecha)
  - (cod_empleado, fecha) → hora_ingreso, hora_salida, cod_justificacion
  - cod_empleado → nombre_empleado **(parcial)**
  - cod_justificacion → descripcion_justificacion (transitiva)
  - horas marcadas + horario → horas_trabajadas, minutos_tardanza (derivado)
- **ASIGNACION_HORARIO** (PK: cod_empleado, cod_horario, fecha_inicio)
  - (cod_empleado, cod_horario, fecha_inicio) → fecha_fin
  - cod_empleado → nombre_empleado **(parcial)**
  - cod_horario → hora_entrada **(parcial)**
- **HORARIO** (PK: cod_horario)
  - cod_horario → nombre_turno, hora_entrada, hora_salida, dias_laborables

**Parciales:** nombre_empleado depende solo de cod_empleado (en ASISTENCIA y ASIGNACION_HORARIO) y hora_entrada solo de cod_horario (en ASIGNACION_HORARIO). Se quitan porque ya están en EMPLEADO y HORARIO.

### A3. Dependencias transitivas (3FN) y atributos derivados

- **EMPLEADO:** cod_empleado → cod_area → nombre_area → nueva tabla **AREA(cod_area, nombre_area)**
- **EMPLEADO:** cod_empleado → cod_cargo → nombre_cargo, sueldo_base → nueva tabla **CARGO(cod_cargo, nombre_cargo, sueldo_base)**
- **ASISTENCIA:** (cod_empleado, fecha) → cod_justificacion → descripcion_justificacion → nueva tabla **JUSTIFICACION(cod_justificacion, descripcion_justificacion)** (cod_justificacion puede quedar vacío)
- **Derivados** (no se guardan, se calculan): horas_trabajadas y minutos_tardanza: salen de las horas marcadas y el horario

### A4. Dependencias funcionales del modelo corregido

- **AREA:** cod_area → nombre_area
- **CARGO:** cod_cargo → nombre_cargo, sueldo_base
- **EMPLEADO:** cod_empleado → nombres, apellidos, cod_area, cod_cargo
- **JUSTIFICACION:** cod_justificacion → descripcion_justificacion
- **ASISTENCIA:** (cod_empleado, fecha) → hora_ingreso, hora_salida, cod_justificacion
- **HORARIO:** cod_horario → nombre_turno, hora_entrada, hora_salida
- **HORARIO_DIA:** (cod_horario, dia_laborable) → solo clave
- **ASIGNACION_HORARIO:** (cod_empleado, cod_horario, fecha_inicio) → fecha_fin

### A5. Modelo normalizado (PK en negrita, FK marcadas)

- **AREA**(**cod_area**, nombre_area)
- **CARGO**(**cod_cargo**, nombre_cargo, sueldo_base)
- **EMPLEADO**(**cod_empleado**, nombres, apellidos, cod_area (FK), cod_cargo (FK))
- **JUSTIFICACION**(**cod_justificacion**, descripcion_justificacion)
- **ASISTENCIA**(**cod_empleado** (FK), **fecha**, hora_ingreso, hora_salida, cod_justificacion (FK))
- **HORARIO**(**cod_horario**, nombre_turno, hora_entrada, hora_salida)
- **HORARIO_DIA**(**cod_horario** (FK), **dia_laborable**)
- **ASIGNACION_HORARIO**(**cod_empleado** (FK), **cod_horario** (FK), **fecha_inicio**, fecha_fin)

## Ejercicio 5. Sistema académico · matrícula y notas

### A1. Atributos que violan la 1FN

- **nota1, nota2, nota3** (MATRICULA): grupo repetitivo, la nota parcial se repite en tres columnas. Solución: tabla **NOTA_PARCIAL**(cod_alumno, cod_curso, nro_parcial, nota), nro_parcial = 1, 2, 3.

### A2. Dependencias funcionales y dependencias parciales (2FN)

- **ALUMNO** (PK: cod_alumno)
  - cod_alumno → nombres, apellidos, fecha_nacimiento, correo, cod_escuela
  - cod_escuela → nombre_escuela (transitiva)
  - fecha_nacimiento → edad (derivado)
- **MATRICULA** (PK: cod_alumno, cod_curso)
  - (cod_alumno, cod_curso) → docente, semestre, nota1, nota2, nota3
  - docente → cod_curso (FNBC)
  - nota1, nota2, nota3 → promedio (derivado)
- **CURSO** (PK: cod_curso)
  - cod_curso → nombre_curso, creditos

**No hay parciales:** en MATRICULA nada depende solo de cod_alumno o solo de cod_curso (un curso puede tener varios docentes). ALUMNO y CURSO tienen PK simple.

### A3. Dependencias transitivas (3FN) y atributos derivados

- **ALUMNO:** cod_alumno → cod_escuela → nombre_escuela → nueva tabla **ESCUELA(cod_escuela, nombre_escuela)**
- **MATRICULA:** (cod_alumno, cod_curso) → docente → cod_curso → nueva tabla **DOCENTE(docente, cod_curso)** (cod_curso es parte de la PK, así que no es transitiva como tal (es el caso de FNBC))
- **Derivados** (no se guardan, se calculan): edad: se calcula con fecha_nacimiento; promedio: se calcula con las notas parciales

### A4. Dependencias funcionales del modelo corregido

- **ESCUELA:** cod_escuela → nombre_escuela
- **ALUMNO:** cod_alumno → cod_escuela, nombres, apellidos, fecha_nacimiento, correo
- **CURSO:** cod_curso → nombre_curso, creditos
- **DOCENTE:** docente → cod_curso
- **MATRICULA:** (cod_alumno, cod_curso) → docente, semestre
- **NOTA_PARCIAL:** (cod_alumno, cod_curso, nro_parcial) → nota

**Nota:** al registrar una matrícula hay que validar que el docente dicte ese curso.

### A5. Modelo normalizado (PK en negrita, FK marcadas)

- **ESCUELA**(**cod_escuela**, nombre_escuela)
- **ALUMNO**(**cod_alumno**, cod_escuela (FK), nombres, apellidos, fecha_nacimiento, correo)
- **CURSO**(**cod_curso**, nombre_curso, creditos)
- **DOCENTE**(**docente**, cod_curso (FK))
- **MATRICULA**(**cod_alumno** (FK), **cod_curso** (FK), docente (FK), semestre)
- **NOTA_PARCIAL**(**cod_alumno** (FK), **cod_curso** (FK), **nro_parcial**, nota)
